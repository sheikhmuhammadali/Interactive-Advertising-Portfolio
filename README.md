# Interactive Advertising Portfolio

A collection of interactive ads, playable experiences, gamified campaigns, and rich-media prototypes built using web technologies.

Developed through my work at **Happy Ads Technologies, Karachi**, this portfolio showcases my experience in interactive advertising, creative development, and engaging digital experiences.

## About

I work at the intersection of design and development, turning creative concepts into interactive web experiences. My focus includes playable ads, gamified advertising, interactive storytelling, and rich-media formats designed to engage users.
